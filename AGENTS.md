# Agent instructions

This repository's instructions are in [CLAUDE.md](CLAUDE.md): code map, commands, gates, code rules, the short product decision list and an index of smaller documents by subject (decision register in [docs/DECISIONS.md](docs/DECISIONS.md), workflow, balance, browser testing, assets, plans). They apply to any agent (Claude Code, Codex, Cursor, Copilot) and to humans. Each main folder (`src/shared`, `src/client`, `src/worker`, `scripts`, `tests`) has a `CLAUDE.md` with the patterns for that area: read the one for the folder you are changing.
