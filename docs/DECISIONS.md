# Decision register

Fernando's product and workflow decisions for Warlock Wars, in the order they were recorded. **Read this before changing gameplay, controls, balance, modes, the UI layout or the workflow, and before undoing anything that looks odd:** it is probably a decision listed here. A row that replaces an earlier one says so; the newer row wins.

Every new decision gets a row here (date, decision, why) in the same PR as the change. If it changes how code is written, also update the affected folder's `CLAUDE.md`; if it changes what the game has or how to contribute, also update `README.md` and `CONTRIBUTING.md`. Dates are day/month (2026). Rows recorded before 25/10 were written in Portuguese and translated on 25/10; quoted UI labels, labels and URL parameters keep their original names.
