# Modelos KayKit (todos os packs grátis)

Os 10 packs grátis do KayKit, de Kay Lousberg ([kaylousberg.com](https://www.kaylousberg.com), [GitHub KayKit-Game-Assets](https://github.com/KayKit-Game-Assets)), todos **CC0** (domínio público: pode usar, mudar e redistribuir sem pedir; o crédito é por cortesia). Ficam aqui para quem contribui achar um modelo sem baixar nada.

**Esta pasta não vai para o jogo no ar:** só o que está em `public/` é publicado a cada deploy. Para usar um modelo:

1. Copie o arquivo para `public/models/...` (no `.gltf`, junto o `.bin` e a textura `.png` que ele cita no campo `uri`; o `.glb` já vem com tudo dentro).
2. Ponha o crédito em `public/CREDITS.txt`, no estilo das entradas KayKit que já estão lá (arquivo, pack, autor, link, licença).
3. Prefira cortar o que não usa (animações, malhas) antes de publicar: cada MB a mais é download para o jogador.

Copiado de cada repositório só o glTF (pastas `Assets/gltf` e `Characters/gltf`, sem alteração), as texturas que ele usa e o `LICENSE.txt` do pack. Ficaram de fora `.fbx`, `.obj`, projetos Godot/Unity e exemplos. Todos os `LICENSE.txt` dizem "Creative Commons Zero, CC0" (lidos em 21/10/2026).
